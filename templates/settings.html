ClickUp

Creates gear-type tasks with box subtasks in your list.

Find at: ClickUp → Settings → Apps → API Token

Open your ClickUp list → the URL shows /list/XXXXXXX — copy that number.

Slack

Sends shipment status updates to a Slack channel when you click "Save & Notify".

Find at: Slack → Your App → Incoming Webhooks

🟤

Auto-Tracking (UPS)

Polls UPS directly for 1Z tracking numbers. Free with a UPS developer account.

Get at: developer.ups.com → My Apps → Add App → Track API

📦

Auto-Tracking (FedEx)

Polls FedEx directly every 2 hours for real-time shipment status. Free with a FedEx developer account.

Get at: developer.fedex.com → My Projects → API Key

🔄

Tracking Fallback (17track)

Used as a fallback if FedEx API is not configured. Checks every 4 hours.

Free at 17track.net/en/api — sign up with email only, no credit card. After logging in, go to API → API Key and copy your key here.

✉️

Email Notifications

Sends a shipment update email to gear@middleschoolmatchup.com when you click "Save & Notify".

Get at: myaccount.google.com/security → App passwords (requires 2-Step Verification on)

🔁

ClickUp Auto-Sync

Imports tasks created directly in ClickUp into the local order registry. Runs automatically every 30 minutes. Click to run immediately.
